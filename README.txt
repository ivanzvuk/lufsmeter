LUFSAnalyzer - Анализатор громкости R128 EBU

Инструкция по установке и запуску:

1. Установите Python 3.8+ с официального сайта: https://python.org
   (не забудьте отметить галочку "Add Python to PATH")

2. Запустите build.bat для создания EXE файла
   или
   Запустите install_dependencies.bat для установки зависимостей и затем run.bat

3. После сборки EXE файл будет в папке dist/

4. Для создания ярлыка на рабочем столе запустите create_shortcut.bat

Особенности программы:
- Поддержка WDM устройств ввода/вывода
- Точное соответствие стандарту R128 EBU
- Настройка времени отображения графиков
- Множественные окна измерений
- Разные режимы каналов: 1+2, 1+1, 2+2

Системные требования:
- Windows 7/8/10/11
- Python 3.8 или новее
- 4GB+ оперативной памяти
- Аудиоустройство с поддержкой WDM
