LUFSAnalyzer v11 — Анализатор громкости R128 EBU
=================================================

Многофункциональный измеритель громкости по стандарту ITU-R BS.1770-4 / EBU R128.
Поддерживает Windows (pyaudio + ASIO) и macOS (sounddevice + BlackHole).

УСТАНОВКА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Windows:
  1. Установите Python 3.8+ (с галочкой "Add Python to PATH")
  2. Запустите install_dependencies.bat
  3. Запустите run.bat (или build.bat для сборки EXE)

macOS:
  1. brew install portaudio ffmpeg
  2. pip install -r requirements_mac.txt
  3. python lufsmeter.py
  (Для захвата системного аудио: brew install blackhole-2ch)

Сборка бинарников описана в build.bat (Windows) и build_mac.sh (macOS).
GitHub Actions автоматически собирает .exe и .dmg при пуше тега v*.

ПОДДЕРЖИВАЕМЫЕ ИСТОЧНИКИ АУДИО
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• WDM Input (микрофон/линейный вход) — Windows, pyaudio
• WDM Output (loopback системного аудио) — Windows, pyaudio as_loopback
• ASIO (любой ASIO-драйвер) — Windows, NAudio (.NET через pythonnet)
• Встроенный микрофон/вход — macOS, sounddevice
• BlackHole (захват системного аудио) — macOS, sounddevice
• SRT-потоки (Secure Reliable Transport) — оба ПК, ffmpeg
• OMT-потоки (Open Media Transport) — оба ПК, TCP-клиент
• Виртуальное устройство (тестовый сигнал 440 Гц) — оба ПК

ИЗМЕРЕНИЕ LUFS (R128 EBU)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Моментальная (Momentary) — 400 мс окно
• Краткосрочная (Short-term) — 3 секунды
• Интегральная (Integrated) — от старта измерения
• Pre-filter (ФВЧ 38 Гц) + RLB weighting
• Смещение калибровки (-10..+10 dB, шаг 0.1)
• Целевой уровень (-50..0 dBFS, шаг 0.5)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
РЕЖИМЫ КАНАЛОВ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• 1+2 (Стерео) — среднее L/R для LUFS
• 1+1 (Моно L) — только левый канал
• 2+2 (Моно R) — только правый канал
• Для ASIO/OMT: любые пары (1+2, 3+4, 5+6...) и моно (1, 2, 3...)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ИНТЕРФЕЙС
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• До 24 окон измерений в автоматической сетке
• Редактируемые названия окон
• Настраиваемая шкала Y (дно -120..0, верх -120..+20 dBFS)
• Время отображения X (1..3600 секунд)
• Цветные графики для каждого канала (polyline + area fill)
• Целевой уровень — красный пунктир
• Рабочий диапазон — зелёная зона вокруг цели
• VU-индикаторы L/R с баллистикой (attack 0.15 с, decay 0.3 с)
• Тёмная тема (меню Вид + тёмный заголовок на Windows 10/11)
• Легенда каналов с кнопками соло (S)
• Сворачиваемая панель настроек и конфигурации каналов

СОЛО-МОНИТОРИНГ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Прослушивание любого канала через системный вывод
• Работает для WDM, ASIO, SRT, OMT, Virtual
• Моно/стерео в зависимости от режима канала
• Очередь с буфером до 262144 сэмплов

ЗАПИСЬ (MULTI-TRACK WAV)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Индивидуальное вооружение каналов (кнопка R)
• Форматы: 44.1/48/96 кГц, 16/24 бит
• Моно и стерео дорожки
• Директории: recordings/YYYYMMDD_HHMMSS/НазваниеОкна/
• Автосохранение на диск каждые 500 мс
• SMPTE таймкод (HH:MM:SS:FF, 25 fps)
• Кнопка "Записать всё" на всех окнах сразу
• Per-драйверные рекордеры для ASIO (разные частоты дискретизации)

СЕТЕВЫЕ ПОТОКИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SRT:
• Авто-сканирование источников через UDP beacon (239.255.255.250:54321)
• Ручной ввод (адрес, порт, streamid, passphrase, mode)
• Режимы: caller, listener, rendezvous
• Декодирование через ffmpeg

OMT (Open Media Transport):
• Авто-сканирование через DNS-SD (_omt._tcp.local)
• Ручной ввод (адрес, порт, имя)
• Бинарный протокол v1, кодек FPA1 (float32)
• До 32 каналов, переменная частота дискретизации
